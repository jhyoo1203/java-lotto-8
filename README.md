# 🧧 로또

## 📌 기능

- [x] **로또 구입**
    - 개당 1,000원
    - 구매 금액에 맞게 자동으로 로또 생성
- [x] **로또 번호 랜덤 생성**
    - 1 ~ 45 사이의 숫자 6개
    - 번호는 오름차순 정렬
    - 로또마다 번호 중복 없음
- [x] **당첨 번호 입력**
    - 1 ~ 45 사이의 숫자 6개
    - 보너스 번호 1개 추가 입력
- [x] **당첨 결과 확인**
    - 3개 일치: 5,000원
    - 4개 일치: 50,000원
    - 5개 일치: 1,500,000원
    - 5개 + 보너스 번호 일치: 30,000,000원
    - 6개 일치: 2,000,000,000원
- [x] **수익률 계산**
    - 수익률 = (총 당첨 금액 ÷ 구매 금액) × 100
    - 소수 둘째 자리에서 반올림

## ⚠️ 검증

1. 입력 도중 오류가 발생할 경우 에러 메시지 출력 후 retry
2. IAE, ISE 등 적절한 예외 사용

- 구입 금액은 1,000원 단위여야 함
    - 숫자 형식 검증
    - 음수 검증
    - 금액 단위 검증
- 로또 번호는 1 ~ 45 사이 숫자만 입력 가능
    - 숫자 형식 검증
    - 범위 검증
- 당첨 번호와 보너스 번호 중복 불가
- 중복 로또 번호 생성 검증
- 입력된 로또 번호 개수 검증
